# Real DOM vs Virtual DOM

## What is DOM?

DOM (Document Object Model) ek programming interface hai jo HTML document ko tree structure ke roop me represent karta hai.

Example:

```html
<body>
  <h1>Hello World</h1>
  <button>Click Me</button>
</body>
```

Browser is HTML ko DOM Tree me convert karta hai.

---

# Real DOM

Real DOM browser ke andar actual DOM tree hota hai.

Jab webpage me koi change hota hai, browser Real DOM ko update karta hai aur page ko dobara render karta hai.

### Advantages

* Browser ka native feature hai.
* Directly HTML elements ko manipulate kar sakte hain.

### Disadvantages

* DOM updates expensive hote hain.
* Chhota sa change bhi performance ko impact kar sakta hai.
* Large applications me slow ho sakta hai.

### Example

```javascript
document.getElementById("title").innerText = "New Title";
```

Har update ke baad browser ko DOM recalculate aur repaint karna pad sakta hai.

---

# Virtual DOM

Virtual DOM React ka ek lightweight copy of Real DOM hai.

React pehle Virtual DOM ko update karta hai, phir purane aur naye Virtual DOM ko compare karta hai.

Is process ko **Diffing Algorithm** kaha jata hai.

React sirf changed elements ko Real DOM me update karta hai.

### Advantages

* Faster updates
* Better performance
* Efficient rendering
* Improved user experience

### Disadvantages

* Extra memory use hoti hai Virtual DOM store karne ke liye.
* Small applications me difference noticeable nahi hota.

---

# How Virtual DOM Works

### Step 1

React Virtual DOM create karta hai.

```jsx
<h1>Hello</h1>
```

### Step 2

State ya Props change hote hain.

```jsx
<h1>Hello Subhash</h1>
```

### Step 3

Naya Virtual DOM create hota hai.

### Step 4

React old aur new Virtual DOM compare karta hai.

### Step 5

Sirf changed part Real DOM me update hota hai.

---

# Real DOM vs Virtual DOM

| Feature      | Real DOM             | Virtual DOM        |
| ------------ | -------------------- | ------------------ |
| Update Speed | Slow                 | Fast               |
| Manipulation | Direct               | Indirect           |
| Memory Usage | Less                 | More               |
| Performance  | Lower                | Higher             |
| Re-rendering | Entire affected tree | Only changed nodes |
| Used In      | Vanilla JavaScript   | React              |

---

# Example Comparison

### Real DOM

```javascript
document.getElementById("count").innerText = count;
```

Directly browser DOM update hota hai.

### Virtual DOM (React)

```jsx
const [count, setCount] = useState(0);

return <h1>{count}</h1>;
```

React Virtual DOM compare karke sirf required changes Real DOM me apply karta hai.

---

# Why React Uses Virtual DOM?

React Virtual DOM use karta hai because:

* Faster UI updates
* Better performance
* Efficient rendering
* Less direct DOM manipulation
* Improved developer experience

---

# Conclusion

Real DOM browser ka actual DOM hota hai, jabki Virtual DOM React dwara maintain ki gayi lightweight copy hoti hai. React Virtual DOM ke through changes ko efficiently compare karta hai aur sirf required updates Real DOM me apply karta hai, jisse application ki performance improve hoti hai.
